## Full description (max 4000 chars) — ~1,760 chars

```
Stop reading flat drawings. ThePrints3D scans a 2D print or construction
drawing and, with minimal input from you, builds a fully interactive 3D model
you can rotate, explode, inspect, and edit.

Point it at a floor plan, elevation, or scanned sheet. ThePrints3D detects the
walls, openings, and rooms, infers the scale, and rises the drawing off the
page into a navigable 3D building — so anyone on the job can see exactly what
the print is describing.

WHAT YOU CAN DO

• Scan any drawing — PDFs, photos, and images all work
• Get a 3D model in seconds with minimal setup
• Explode the model to see how it goes together
• Inspect any element — doors, windows, walls, rooms
• Edit and refine the result to match the real print
• Organize by trade with trade-specific layers (framing, electrical, plumbing,
  HVAC, and more)
• Measure real-world distances right on the model
• Toggle layers on and off to focus on one system at a time
• Works offline — processing happens on your device

BUILT FOR THE TRADES
Whether you're framing, running conduit, roughing in plumbing, or walking a
client through a space, ThePrints3D turns an abstract set of lines into
something you can actually see and hold. Trade-specific layering keeps each
discipline separate, so you show only what matters.

PRIVATE BY DESIGN
Your drawings never have to leave your device. Everything from scan to 3D
model can run locally.

From the 3D Learning Family by Mitchell Lorin McKnight — makers of CircuiTry3D
and Automotive3D.
```

## Claims the app must actually honour

The listing promises these. Keep them true:

- **Offline / on-device processing** — no drawing leaves the device
- **Measure on the model** — tap-to-measure in 3D
- **Layer toggles** — and they must do what they say
- **Editing** — every element the model builds is editable
